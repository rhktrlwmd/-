# Имитационное моделирование

Репозиторий содержит восемь лабораторных работ по курсу `Имитационное моделирование`, оформленных в едином стиле:

- исходники моделей в литературном формате `qmd`;
- автоматически извлекаемый чистый код на `Julia`;
- ноутбуки `ipynb`;
- отчёты в `md`, `docx`, `pdf`;
- презентации в `md`, `html`, `pdf`;
- архивы исходных материалов для релизов.

## Структура

- `labs/lab01` ... `labs/lab08` — отдельные лабораторные работы;
- `references.bib` — общая библиография;
- `course-info.json` — титульные данные для отчётов и презентаций;
- `scripts/build.py` — единая сборка всех материалов.

## Сборка

```bash
python3 scripts/build.py
```

Скрипт:

1. извлекает код `Julia` из `qmd`-источников;
2. генерирует `ipynb`;
3. запускает вычислительные сценарии;
4. строит графики и таблицы;
5. собирает отчёты и презентации в требуемые форматы;
6. упаковывает исходные материалы в архивы для релиза.

## Публикация

Перед публикацией:

1. заполните `course-info.json`;
2. добавьте ссылки на скринкасты в итоговый `lms-response.md`;
3. привяжите репозиторий к нужному GitHub remote;
4. создайте релиз с версией `v1.0.0` и приложите файлы из каталогов `labs/*/release`.
